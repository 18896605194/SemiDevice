xyz SECS / GEM 协议栈

从链路到报文再到数据模型完全自研的 SECS-II / HSMS-SS 实现，内置 GEM 五类采集器与 SEMI E87 / E84 标准支持， 让设备一次通过客户产线的联机验收。

HSMS-SS

HSMS-SS 高速消息链路

xyz.Secs 提供 HSMS-SS 单会话模式的完整实现：设备既可以主动连接 EAP（HsmsConnector）， 也可以被动监听等待上位接入（HsmsListener），链路建立、心跳与异常恢复全自动处理。

  • Select / Deselect / Separate / Linktest 全状态机管理
  • T3 / T5 / T6 / T7 / T8 全套超时参数可配置
  • 系统字节与设备 ID 校验，重复事务跟踪
  • 断线自动重连，事务在恢复后有序收尾

SECS-II

SECS-II 全格式编解码

自研编解码器覆盖全部数据格式与边界场景，1 / 2 字节长度头自动适配，任意嵌套结构可直读直写。

L 列表 A ASCII B 二进制 Boolean I1 – I8 有符号整型 U1 – U8 无符号整型 F4 / F8 浮点 1 / 2 字节长度头

双向会话

主侧发起、副侧应答完整支持：S1F1/S1F2 在线确认、S1F13/S1F14 建链握手、S2F31 时间同步等常见事务开箱可用。

事务超时治理

每个未决事务挂 T3 计时，重连 T5 间隔、控制事务 T6、连接建立 T7、NOT_SELECTED T8——异常场景按标准收尾。

报文级日志

原始字节与解码视图双轨落盘，联机问题可以精确定位到具体 item，无需抓包工具。

GEM Data Collection

GEM 五类采集器

编号体系在框架内统一规划，启动时自动合并机型编号表，一键快照采集——设备侧 GEM 数据模型不再靠手拼。

采集类型编号区间内容典型上报
ECID 设备常数10000 – 29999工艺与运行参数，支持 S2F15 远程设定S2F16 应答
SVID 状态变量30000 – 49999设备状态、腔体温度、真空度等实时值S6F3 / S1F4
ALID 报警50000 – 69999报警置位 / 清除与描述文本S5F1
CEID 事件70000 – 89999装卸完成、工艺开始 / 结束等节点事件S6F11
DVID 数据变量90000 – 99999追溯数据、批次与载具信息随事件报告
SEMI Standards

E87 载具管理 · E84 并行 IO

SEMI E87 载具管理服务

IE87Callback 将载具到达 / 离开、Carrier ID 读取、Slot Map 读取、装 / 卸载完成等节点以回调形式暴露， 与 RFID 驱动和晶圆账联动，EAP 侧需要的每一个载具动作都有标准事件挂钩。

SEMI E84 并行 IO 交接

E84Component 实现 VALID / CS0 / CS1 / AM_AVBL / TR_REQ / BUSY / COMPT 信号组的完整时序， 光幕互锁与超时计时保护内置——AMHS 对接不再靠继电器图纸硬捋。
