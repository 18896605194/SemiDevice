xyz ECF 设备控制平台

Equipment Control Framework —— 平台核心。WPF 客户端与 gRPC 后端服务前后端分离，组件树按配置装配， 机型以插件形式热插拔，为半导体设备提供从 IO 到界面的完整上位机软件底座。

Architecture

六层架构，职责清晰

客户端不引用任何后端工程，全部通过 xyz.Shared 契约以 code-first gRPC 通信——界面与控制彻底解耦，任一层可独立替换。

客户端层xyz.Client · WPF + MVVM
主程序壳 / 页面宿主 设置 / EC 参数 IO 监控 报警中心 手动操作 数据中心 配方管理 机型客户端插件
⇅　gRPC 契约（xyz.Shared · DTO + 服务接口）
服务层xyz.GrpcHost · xyz.Service
托盘常驻宿主 报警 / 事件 / 用户权限 数据 / 日志 / 图表服务 单实例互斥保护
模块层xyz.Modules · 机型插件
Load Port 模块 Robot 机械手模块 Clean 清洗腔模块 Transfer 搬运调度 E84 交接模块 OnScan 状态机
组件层xyz.Components · 组件树
PLC 组件 轴 / 气缸 / 阀门 / 传感器 RFID 晶圆账 Wafer Ledger GEM 采集器 三色灯
驱动层xyz.Drivers · 纯协议实现
串口 / TCP 通信框架 FCD Load Port FCD RFID 机械手 TCP 协议 TwinCAT ADS
数据层xyz.Database · SQLite 分库
xyz.db 业务库 io.db 秒级采样库 90 天历史留存 可切换企业级数据库
Plugin Architecture

平台 + 机型插件
换型不改平台

平台壳（GrpcHost / Client）不引用任何机型工程。机型以后端模块、客户端插件、专属控件三件套独立开发， 编译后部署到 Modules\<机型>\ 目录，启动时自动扫描装配——同一套平台并行支撑多机型研发，互不干扰。

  • 机型 DLL 编译即部署，无需改动平台代码
  • 机型专属手动操作页、HMI 控件与语言包随插件下发
  • IO 点表以 CSV 点表管理，随机型插件走版本管理
  • 首个落地机型：35021 清洗设备（清洗腔 + Load Port + 机械手）
Modules/ — 机型插件目录
// 启动时扫描 Modules/<机型>/ 自动装配

Component Library

设备组件库，即配即用

后端按 sc.xml 配置以反射构建组件树；设备参数 ec.xml 随组件树自动生成，无需手写界面绑定。

Load Port 花篮组件

槽位、Foup 壳、插针状态建模，对接 E87 载具事件。

晶圆 Wafer 组件

槽位级晶圆存在性、编号与状态，驱动晶圆账记账。

腔体 Chamber 组件

工艺腔卡片视图，TimedOperation 定时工艺流程编排。

轴 / 气缸 / 阀门 / 传感器

命令块与状态块数据协议，同步号校验与断线重连。

RFID 载具识读

FCD RFID 协议，载具 ID 读取事件化上抛 EAP。

三色灯 / 报警组件

ALID 报警体系，报出 / 清除入库，灯色联动。

Drivers & Connectivity

设备驱动套件

纯协议实现、与业务解耦的驱动层，新硬件接入只需实现一个驱动类。

FCD Load Port

B 类帧协议驱动：Dock/Undock、Mapping、门开闭与插针状态轮询，串口 / TCP 双通道。

晶圆机械手

Reje 四臂机械手 TCP 协议：取放 / 回零 / 速度与轴位控制，晶圆事件推送与心跳保活。

PLC · TwinCAT ADS

倍福 ADS 协议接入：命令块 / 状态块整块读写，50ms 轮询缓存，断线自动重连恢复。

SEMI E84 并行 IO

VALID/CS0/CS1、L_REQ/U_REQ、HO_AVBL 全信号时序，光幕互锁与 E84 超时计时保护。

Transfer 搬运调度

TransferManager 统一调度多工位间晶圆搬运路径，冲突排队与异常中断恢复。

互锁 Interlock 层

基于条件与规则表的互锁引擎设计：动作许可集中判定，三值逻辑处理未知状态。

Data & Traceability

数据中心 · 晶圆追溯

生产数据与 IO 采样分库存储避免锁竞争，历史留存 90 天，客户端随时回查。

Wafer Ledger 晶圆账

全系统唯一「哪个槽位有哪片晶圆」账本，事件驱动记账，90 天历史入库可查轨迹。

实时 / 历史趋势

IO 秒级采样写入独立 io.db，ScottPlot 实时曲线与数据中心历史查询双视图。

报警与事件审计

ALID 报警报出 / 清除全记录，用户操作与权限变更留痕，满足产线审计要求。
