# CDS 原生控件布局编辑器

一个槽加补液、排液、供液管路的独立 WPF 编辑页面，暂不添加阀门。只引用客户端项目，不启动设备框架，不连接 PLC、RPC，不写 IO。

复用现有控件：

- `TankVisual3D`：与 `TankScene` 相同的透明槽及液体模型。
- `FluidRouteVisual3D`：透明管壁、圆角管线和水流动画，与 `FluidPipe` 使用同一个渲染控件。
- `SignalLamp`、`TankModel`、现有暗色资源与 Material Design 样式。

槽和管路使用同一个 `Viewport3D`，连接口随槽的变换计算。编辑层使用固定正视投影，和原生三维模型共用画布坐标。

## 运行

```powershell
dotnet run --project D:\Code\tools\CdsLayoutPreview\CdsLayoutPreview.csproj
```

## 编辑操作

1. **选择 / 拖动**：直接拖动槽或外部接口。端点跟随组件移动，原有首尾水平或垂直管段尽量保持方向。位置按 10 个画布单位吸附，不受窗口缩放影响。拖动期间相关管路暂用轻量线框跟随，松开后恢复原生管路外观。
2. **画管路**：点蓝色连接口作为起点，在画布上依次点选途经位置，最后点击另一个蓝色连接口。绘制时自动插入直角拐点。新管路的模拟状态从右侧选择。若两端已有管路，可选中旧管路修改，或删除后重画。
3. **调整拐点**：先点击管线，或在右侧对象列表选择管路，再拖动方形手柄。拐点允许自由移动，不强制维持正交。双击线段增加拐点；选中拐点后按 Delete 删除拐点；仅选中管路时按 Delete 删除整条管路。槽和外部接口在这一版中保留，不能删除。
4. **撤销 / 重做**：Ctrl+Z / Ctrl+Y。一次拖动作为一步操作；最多保留 60 步撤销历史。Esc 或右键取消未完成绘制或当前拖动。
5. **保存 / 另存为**：首次保存选择 XML 文件路径，后续 Ctrl+S 保存到该路径。采用临时文件写完后替换，保存失败保留旧文件。不会自动覆盖程序自带的示例配置。
6. **打开 / 重新加载**：Ctrl+O 打开布局，“重新加载”读取当前文件。打开、重新加载或关闭窗口前，未保存的改动会提示保存、放弃或取消。文件先校验再替换画面，加载失败保留现有布局。
7. **运行预览**：隐藏网格和编辑手柄、锁定布局。右侧切换补液、排液、供液和停止，或切换离散液位档位。回到“选择 / 拖动”继续编辑。
8. **管路外观与动画**：选中管路后可设置管径、管壁厚度、转弯半径、管壁不透明度、管壁颜色、液流颜色、动画速度、介质名称、反向流动、显示液芯和播放动画。点击“应用管路属性”更新显示，整组属性支持撤销和重做。保存、切换对象或进入运行预览时也会尝试应用有效输入；非法数值保留输入并给出原因，不会写入布局。

液位高度只是档位示意，不表示真实液位百分比。流动动画只表示模拟运行路径。

## 布局文件范围

`CdsLayout.xml` 是随程序附带的初始布局，构建时复制到输出目录。用户保存的布局另选位置；下次启动后用“打开”读取。

这一版支持单页面、一个槽及已有外部接口，可增删管路、增删和移动拐点。布局保存图元 ID、位置、尺寸、组件路径、管路两端、途经拐点、介质及模拟状态。配置版本为 1，最多 200 条管路、每条最多 100 个拐点；未知图元、重复 ID、无效连接口及非法坐标会被拒绝。

每条管路的 `PreviewMode` 指定模拟操作（`fill`、`supply`、`drain`），仅用于显示，不从组件路径推断控制流程。`ComponentRoot`、`Component`、`Medium` 等字段按原值保存，本编辑器不解析成后端对象。仅支持 `StandardTank` 模板，尚未接入主程序导航、真实状态绑定或设备操作。

## 生成原生渲染截图

编辑器采用固定的 `PreviewPage.xaml`（View）和 `LayoutEditorViewModel.cs`（ViewModel，含属性输入与应用命令）。鼠标捕获、场景投影和渲染保留在 View。每次保存只产生布局 XML，不生成新的 XAML 或 C# 文件。

新增管路属性作为可选 XML 属性保存：`Diameter`、`WallThickness`、`BendRadius`、`WallOpacity`、`WallColor`、`FlowColor`、`FlowSpeed`、`ReverseFlow`、`IsFilled`、`IsAnimationEnabled`。旧版布局缺少这些属性时采用原来的默认外观，仍可加载。显示尺寸使用画布单位，不代表实际硬件的毫米尺寸。

```powershell
dotnet build D:\Code\tools\CdsLayoutPreview\CdsLayoutPreview.csproj
Start-Process -FilePath D:\Code\tools\CdsLayoutPreview\bin\Debug\net10.0-windows\CdsLayoutPreview.exe -ArgumentList '--render','D:\Code\tools\CdsLayoutPreview\previews' -WindowStyle Hidden -Wait
```

输出编辑界面、较小窗口及供液、补液、排液、停止截图，验证液位档位切换和缩放坐标。截图使用 WPF 自身的 `RenderTargetBitmap`。运行异常写入可执行文件旁的 `preview-error.log`。

将 `--render` 改为 `--self-test` 可运行编辑流程验证：拖动槽和接口、连接端跟随、撤销重做、取消拖动、插入/拖动/删除拐点、删除/重画管路、属性修改、预览锁定、保存加载一致性、加载失败保留布局、保存失败保留文件及配置校验。结果写入输出目录的 `editor-checks.txt`，测试文件也只写入该输出目录。

改为 `--benchmark` 可记录拖动槽和拐点各 60 次的 UI 线程处理耗时、内存分配及路径重建次数，结果写入 `editor-benchmark.txt`。它衡量事件处理开销，不等同于显示帧率。编辑器按框架 `FluidPipe` 的 0.01 比例将画布单位换算为管路场景单位；网格背景只在画布尺寸或编辑模式改变时重建，未变化的管路路径不重新赋值。
# 管路文字

选中管路或点击管路旁的文字，在右侧“管路旁文字”中修改，然后应用属性或保存。留空隐藏文字。文字绑定到管路路径的中点，拖动槽、接口或拐点时实时跟随；编辑和运行预览均显示，支持撤销、重做及保存加载。XML 使用每条 `Pipe` 的 `Text` 属性，旧文件缺少此属性时显示管路 ID。
