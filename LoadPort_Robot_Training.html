第 0 章 · 背景知识：先搞清楚我们在讲什么

0.1 一片晶圆的「最后一公里」

晶圆在前段做完几百道工序后，是装在载具（Carrier）里被搬运的。 载具由 OHT（空中搬运车）/ AGV / 人工送到设备的载具接口上， 设备内部再把它取出来送进工艺腔，加工完再放回去。这中间「从载具到工艺腔」的这一段，就是 EFEM 负责的。

Load Port 和 Robot，正是 EFEM 里最核心的两个部件：Load Port 是「门和接口」，Robot 是「手和脚」。

0.2 载具家族：先认识它们，才能看懂 Load Port

关键概念：槽位（Slot） FOUP 内部有 25 个槽位（slot），每个槽位只能放一片晶圆。槽位编号从下往上通常为 1～25。 Mapping（扫片）就是去确认「哪个槽里有片、哪个槽是空的、有没有一个槽插了两片」。这是新人最先要建立的空间概念。

0.4 为什么必须是「微环境」？——洁净与污染

颗粒（Particle）的杀伤力

  • 一颗 0.1 µm 级别的颗粒落在关键层上，就可能直接毁掉一颗 die。
  • 300 mm 时代线宽远小于颗粒尺寸，因此不能靠「把整个厂房做成超净」来解决问题。
  • 做法改为：FOUP 内 → EFEM 内 → 工艺腔内 形成一条连续的微环境通道，外界只暴露载具外表面。

污染的几个来源

  • 机械摩擦：Clamp、Latch、导轨、皮带磨损产生颗粒。
  • 气流组织不良：EFEM 内出现涡流，颗粒反复扬起。
  • 密封失效：Port Door 密封圈老化，外界空气渗入。
  • 人为因素：开门作业、擦拭方式不对、手套带静电吸尘。
  • AMC：气态分子污染物（酸性、碱性、有机、掺杂），靠化学过滤器处理。
新人最容易犯的错 载具放在 Load Port 上之后，在设备还没关门完成的情况下伸手去碰 FOUP 或 Port Door。 正确做法：确认设备状态指示为「非取放状态」、Robot 已停止，再按 SOP 操作。

模块一硬件结构：它身上有哪些东西

用一句话形容 Load Port：它是一个「带门、带锁、带眼睛的停车位」。 载具（FOUP）开进来停下，它负责停稳、锁住、把载具的门打开、看清楚里面有几片晶圆。

模块二正常动作：它平时一步一步怎么动

场景：OHT 送来一盒 FOUP → 设备把里面的晶圆取出来加工 → 加工完放回去 → OHT 把 FOUP 取走。 整个过程分成 4 个阶段、10 个动作。

新人最常问的 4 个问题

Q1：为什么一定要先夹紧再开门？
因为开门时 Latch Key 会旋转、Door Opener 会往外拉，载具会被带动。如果不夹紧，载具可能被拉偏甚至移位，导致后续机械手取片位置不对。

Q2：为什么一定要做 Mapping？
因为设备「看不见」载具里面。机械手如果去一个空槽取片，会白跑一趟；如果槽里插了两片，直接去取就会碰片。Mapping 就是提前把「哪里有几片」问清楚。

Q3：载具放歪了会怎么样？
定位销就是用来防止这件事的。如果载具真的放歪（比如台面有颗粒），Clamp 可能夹不到位，或者 Latch Key 对不准锁孔，设备会在「夹紧」或「解锁」这一步报超时。

Q4：这 10 个动作要多久？
远比你想象的快——整套开门+扫片通常在几秒内完成。这也是为什么不能随便伸手进去，机构动作速度很快。

模块三E84 模块：它怎么和 OHT「说话」

先搞清楚为什么要「说话」 OHT 是一台自动搬运车，Load Port 是接口。两边都不是人，必须事先约好一套「对话规则」， 否则会出事故：OHT 以为可以放，设备却还没准备好；或者设备还没关门，OHT 就伸手来取。
这套规则就是 SEMI E84（载具交接的并行 I/O 接口）。

E84 是什么？

  • 它不是网络协议，而是几根实实在在的信号线（硬线）。
  • 双方通过「把线拉高 / 拉低」来传递意思，一方发、另一方读。
  • 因为走硬线，所以快、可靠、不依赖网络——哪怕 MES 断了，OHT 照样能把片子送进来。
  • 接口就叫 PIO（Parallel I/O，并行 I/O），也就是模块一里的第 10 号部件。
打个比方：两个人交接一个箱子 甲（设备）：我这边有空位了 → 乙（OHT）：我要放箱子过来 → 甲：好，你放 → 乙：放好了 → 甲：收到，我接手了。
每一步都要等对方回应，谁也不能抢跑。E84 就是把这段话变成了电信号。

不同厂商实现可能略有差异，下表是示意性的常见信号，实际以设备的 PIO 接口规格书为准。

场景一：OHT 把载具送过来（Load）

  1. 设备说「我要片」设备置 L_REQ，表示这个 Load Port 需要一个载具。
  2. 设备说「位置是空的」设备置 HO_AVBL，表示交接位可用。
  3. OHT 说「我来了」OHT 置 TR_REQ，表示它要执行这次交接。
  4. 设备说「可以放」设备置 READY，OHT 开始下降放载具。
  5. OHT 放好OHT 置 BUSY，放完置 COMPT。
  6. 设备确认接手设备读 COMPT，撤销 L_REQ，OHT 撤销 TR_REQ、BUSY、COMPT，然后离开。
  7. 回到模块二的第 1 步Presence Sensor 确认有载具，接下来就是「夹 → 读 → 开 → 扫」。

场景二：OHT 把载具取走（Unload）

  1. 设备完成取放片、关门锁紧、Clamp 松开后，置 U_REQ：「我这边好了，来取吧」。
  2. OHT 置 TR_REQ 响应。
  3. 设备置 READY，表示可以取。
  4. OHT 取走载具，置 COMPT。
  5. 设备撤销 U_REQ，OHT 撤销相关信号，本站恢复空闲。

场景三：异常与急停（ES）

  • OHT 置 ES（急停）时，设备必须停止动作并给出响应。
  • 设备侧出现报警、门未关好、Robot 异常时，不能给 READY，否则 OHT 会以为可以动作。
  • 任何一方信号异常，握手就会「卡住」，表现为超时报警。

E84 出问题的典型现象

现象可能是哪一侧的问题先看什么
OHT 停在设备前不动，报握手超时设备侧没给 READY / HO_AVBLLoad Port 是不是被禁用（Disable）或处于手动模式
载具放下后设备迟迟不动作Presence Sensor 没识别到，或 E84 没走完IO 监视页：各信号是否按顺序变化
载具取不走，OHT 反复重试设备没置 U_REQ，或 Clamp 没松开设备是否还在「关门/松夹」阶段、有无未清报警
信号时好时坏端子接触不良、线缆松动端子排紧固、线缆走向有无拉扯
排查三步走 ① 看状态：Load Port 是否 Enable、有无未清报警、是否处于手动。
② 看信号：打开 IO 监视页，看哪个信号该变没变。
③ 看时序：拿标准时序图对比，找出卡在第几步。
不要凭记忆短接信号线——这是最容易被禁止的操作之一。
E84 和 SECS/GEM 别搞混 E84（PIO）：设备 ↔ OHT，硬线信号，毫秒级，负责「谁在什么时候能动手」。
SECS/GEM：设备 ↔ 主机（MES/EAP），走网络，秒级，负责「这批片子是谁的、该用什么配方」。
两条通道互相独立，排查时分开看。

进阶有余力再看

下面这些属于第二阶段的内容，第一次学可以跳过。

定位销为什么要用「一圆销 + 一菱形销」？
平面上的刚体有 6 个自由度（3 个平移 + 3 个旋转）。如果两个销都是圆柱销，会「过约束」， 载具放不下去或产生应力。经典做法是：圆销约束 2 个平移自由度，菱形销只约束 1 个平移 + 1 个旋转， 底面再约束剩下的自由度——刚好 6 个全约束，且可重复装配。这就是 Kinematic Coupling。
Mapping 的四种典型结果与处理原则
状态含义处理原则
Normal槽位有且仅有一片，位置正常正常取片
Empty空槽跳过，不取
Double / Cross一个槽位两片，或晶圆斜插跨两槽禁止自动取片，按 SOP 隔离并人工确认
UnknownMapping 失败或传感器异常先查传感器与光路，不要盲目继续
Port Door 密封失效会带来什么后果？
EFEM 内部通常维持微正压，靠 Port Door 密封圈隔绝外界。密封失效会导致： ① 外界颗粒进入，Particle 超标，影响良率； ② 湿度/氧含量波动，对铜、低 k 等工艺产生氧化风险； ③ 压力波动导致内部气流组织紊乱，触发压力报警。

第 2 章 · Robot（搬运机械手）

2.1 一句话定义

定义 EFEM 内的 Robot 是负责在载具、对中台（Aligner）、缓存位（Buffer）与工艺腔之间搬运晶圆的机械手。 它不改变晶圆的工艺状态，只负责「安全、快速、无污染、不碰伤」地移动晶圆。

2.2 常见构型对比

构型特点典型场景关注点

2.3 运动学：R-θ-Z

绝大多数 EFEM 机械手的定位由三个自由度决定：

R（Radial）
末端沿径向伸出/缩回的距离，决定「伸多远」
θ（Theta）
整体旋转角度，决定「朝哪个方向」
Z（Z-axis）
升降高度，决定「对哪一层槽位 / 哪个工位」

因此一个「取片位置」在控制器里通常就是一组 (R, θ, Z) 参数，称为一个 Station 或 Position。

图 2-1　R-θ-Z 三自由度：径向伸出、整体旋转、升降定位

2.4 末端执行器（Blade）与晶圆夹持

常见夹持方式

  • 真空吸附（Vacuum Chuck）：最常用。靠负压把晶圆吸在 blade 背面，需要真空检测确认「吸住了」。
  • 边缘夹持（Edge Grip）：夹住晶圆边缘，适合不能背面接触的场合。
  • 伯努利吸盘：靠气流产生负压，非接触，颗粒风险最低，但稳定性要求高。

Blade 上常见的传感器

  • 真空压力开关：判断是否有片（有片时真空度建立更快）。
  • 边缘/有无片传感器：辅助判断晶圆是否在正确位置。
  • Mapping 传感器：部分机械手自带，用于扫载具槽位。
「有片判断」是高频故障点 真空吸附的「有片 / 无片」判断，本质上靠真空压力变化。吸盘老化、管路微漏、气源波动都会导致误判， 表现为「明明吸住了却报无片」或「空 blade 却报有片」。排查时优先查吸盘与管路，而不是急着改参数。

2.5 示教（Teach）：新人最该理解的动作

示教就是把机械手移动到正确位置，并把这个位置的 (R, θ, Z) 记录下来。 每个取放点（Load Port 的每个槽、Aligner、Buffer、各工艺腔）都有一个示教位置。

示教位置为什么会「漂」？

机械原因

  • 皮带张力变化、连杆间隙变大
  • 紧固件松动、轴承磨损
  • 碰撞后轻微变形
  • 更换电机/编码器后零点丢失

环境与其它原因

  • 温度变化引起热胀冷缩
  • 载具定位销磨损导致载具位置变化
  • 设备搬迁、调水平后基准改变
  • 软件/固件升级后参数被重置
示教的安全顺序 1) 降速 → 2) 单步 / 手动模式 → 3) 确认无人处于运动范围内 → 4) 记录并备份原参数 → 5) 修改后先低速验证 → 6) 再做多片连续验证。 任何示教都必须先备份原始参数。

指标含义为什么重要

第 3 章 · Load Port 与 Robot 如何协同

3.1 一次完整的搬运流程

第 1 章模块二讲的是 Load Port 自己的 10 个动作；这里把 Robot 的动作也加进来， 看整条链路是怎么串起来的：

  1. 载具到位OHT 把 FOUP 放到 Load Port，E84 握手完成。
  2. 开门扫片Clamp → Latch 解锁 → 开门 → Mapping，生成槽位状态。
  3. 取片Robot 按 Mapping 结果到指定槽位取片（R-θ-Z 到位 → 真空吸附 → 确认有片 → 抬起）。
  4. 对中送到 Aligner 做圆心/缺口对中，保证后续工艺定位精度。
  5. 进腔送入工艺腔（或经 VTM 机械手转交）。
  6. 加工工艺腔执行配方。
  7. 回片Robot 取回晶圆，按规则放回 FOUP 槽位。
  8. 关门出站关门锁紧 → 松夹 → E84 通知 OHT 取走。
一个重要的判断习惯 遇到报警先问自己三个问题：
① 报警发生在「哪个阶段」？（进站 / 开门 / 扫片 / 取片 / 回片 / 出站）
② 是「载具侧」问题还是「机械手侧」问题？
③ 是「机械动作」问题还是「信号/通讯」问题？
这三问能让你在 80% 的情况下快速缩小范围。

3.2 与主机通讯：SECS/GEM 概览

设备状态最终要上报给 MES/EAP，靠的是 SECS/GEM 体系：

标准作用与 Load Port / Robot 的关系
SECS-II（E5）定义消息格式上报载具 ID、槽位状态、报警
GEM（E30）定义通用设备行为模型状态机、报警管理、远程命令
HSMS（E37）基于 TCP/IP 的通讯层实际传输通道
E40加工管理批次与配方关联
E87 / E90载具管理 / 基板追踪载具与晶圆的全程追溯
E84载具交接并行 I/O与 OHT 的实时握手（不经过 MES）
区分清楚 E84（PIO）是设备 ↔ OHT 之间的硬线信号，毫秒级、实时；
SECS/GEM是设备 ↔ 主机之间的消息通讯，秒级、走网络。
两者是两条独立的通道，排查时不要混在一起看。

3.3 联机问题排查思路

  1. 看现象归属是 OHT 报错、设备报错，还是 MES 侧任务卡住？
  2. 看硬线PIO 各信号实际电平与期望是否一致（万用表/示波器/IO 监视页）。
  3. 看设备状态Load Port 是否处于 Enable、是否 Manual、是否有未清报警。
  4. 看软件状态SECS 通讯是否 Online、Host 是否下发了正确任务。
  5. 看历史报警时间戳 + 事件日志，往往能直接定位到是哪一步超时。
  6. 记录并升级把信号时序图、日志、现象描述整理好再升级给厂商，效率最高。

第 4 章 · 安全规范

最重要的三条 ① 进入设备运动区域前，必须执行 LOTO（挂牌上锁） 或设备规定的安全隔离流程。
② 绝不绕过 Interlock（安全联锁），绝不用短接线让设备「先跑起来」。
③ 不确定是否安全时，停下来问，不要凭猜测动手。

4.1 机械安全

  • Robot 运动范围、Load Port 门机构、升降机构都是夹伤/撞伤风险点。
  • 急停（E-Stop）位置要在上岗第一天就记住，并知道按下后设备会处于什么状态。
  • 断电后部分机构可能仍有重力下落风险，需确认抱闸/支撑是否有效。
  • 手动模式下操作必须低速、单步，并保持手在安全位置。

4.2 电气安全

  • 只做授权范围内的电气作业；带电测量必须使用合格仪表与防护。
  • 断电后确认电容放电时间，再接触端子。
  • 更换板卡/传感器前记录原始接线与参数。

4.3 气动与真空安全

  • 断气前确认机构不会因失压而掉落或移动。
  • 拆卸气管前先泄压，避免气管甩动伤人。
  • 真空管路残压与吸附的晶圆同样需要处理。

4.4 洁净室与 ESD 规范

洁净室行为

  • 按规定穿无尘服、手套、口罩，不化浓妆、不佩戴饰品。
  • 不在设备开口处快速走动、说话、咳嗽。
  • 物品掉落后不擅自捡起放入设备。
  • 不在洁净室内使用非洁净纸笔。

ESD 防护

  • 接触晶圆/载具/电子板卡前先做静电释放。
  • 使用防静电手套与腕带（按厂内规定）。
  • 板卡用防静电袋存放，不裸手拿。

4.5 异常处理原则

  1. 先停：出现异常声响、异味、冒烟、撞片，第一时间急停。
  2. 再隔离：断电/断气，隔离能量源，防止二次伤害。
  3. 后记录：拍照、记录报警号与时间，不要急于复位。
  4. 再上报：按厂内流程通知，不擅自拆解关键部件。

附录 B · 自测题

前 8 题为选择题（点选即可判分），后 6 题为简答题（点击展开参考答案）。建议闭卷作答。

1. Load Port 的核心作用是什么？

正确答案：B。加工是工艺腔的事，腔间传输通常是真空机械手的事。

2. 「一圆销 + 一菱形销」这种定位方式的设计目的是？

正确答案：C。这是运动学定位（Kinematic Coupling）的经典做法。

3. Mapping 报出「Double / Cross」，正确处理方式是？

正确答案：A。双片/斜插意味着有碰片风险，必须人工介入。

4. 机械手 R-θ-Z 中，Z 轴代表什么？

正确答案：D。R = 径向，θ = 旋转，Z = 升降。

5. 「明明吸住了晶圆却报无片」，最应该优先排查什么？

正确答案：B。有片/无片判断依赖真空压力变化，吸盘老化或管路微漏是首要嫌疑。

6. E84（PIO）与 SECS/GEM 的区别是？

正确答案：C。两条通道独立，排查时不要混在一起。

7. 关于示教（Teach），下列做法正确的是？

正确答案：A。示教是高风险作业，必须备份 + 降速 + 双人确认（按厂内规定）。

8. 下列哪一项属于「一票否决」的安全红线？

正确答案：D。绕过 Interlock 是最严重的安全违规。

简答题

9. 请按顺序说出 Load Port 自动开门到出站的完整时序（至少 8 步）。
接 → 夹 → 读 → 开 → 扫 → 取 → 还 → 关 → 松 → 走。
即：载具交接到位 → Clamp 夹紧定位 → 读取载具 ID → Latch 解锁并开门 → Mapping 扫片 → Robot 取片（经 Aligner 对中）→ 加工后回片 → 关门锁紧 → Clamp 松开 → PIO 通知 OHT 取走。
10. 为什么 300 mm 世代要使用 EFEM 微环境，而不是把整个厂房做成超净？
线宽远小于颗粒尺寸，颗粒对良率影响极大；把整个厂房维持在极高洁净度成本过高且难以实现。 微环境方案只让载具内部、EFEM 内部和工艺腔形成连续洁净通道，外界仅暴露载具外表面，成本与效果更优。
11. 机械手的定位精度为什么会随时间漂移？举出至少 4 个原因。
① 皮带张力变化、连杆间隙变大；② 紧固件松动、轴承磨损；③ 碰撞后轻微变形； ④ 更换电机/编码器后零点丢失；⑤ 温度变化导致热胀冷缩；⑥ 载具定位销磨损使载具位置改变； ⑦ 设备搬迁或调水平后基准变化；⑧ 固件/软件升级导致参数重置。
12. 遇到「Load Port 开门超时」报警，你的排查顺序是什么？
① 确认设备处于安全状态（必要时 LOTO），不要强行拉门；
② 查 Door Opener 真空是否建立（吸盘/管路）；
③ 查 Latch Key 是否打滑、锁扣是否卡死（换备用载具做对照）；
④ 查导轨阻力、润滑状态与门密封圈是否粘黏；
⑤ 查相关到位传感器信号是否正常；
⑥ 记录现象与日志，超出授权范围按流程升级厂商。
13. Port Door 密封失效会带来哪些后果？
外界颗粒进入导致 Particle 超标、影响良率；湿度/氧含量波动可能引起晶圆氧化； EFEM 内部压力波动导致气流组织紊乱，可能触发压力报警。
14. 请用一句话向完全不懂的人解释「Load Port 和 Robot 的关系」。
参考答法：Load Port 是设备的「门和接口」，负责把载具接住、打开、并把里面的晶圆情况看清楚； Robot 是设备的「手」，负责按顺序把晶圆从载具里拿进拿出。 一个管接口，一个管搬运，合起来就是 EFEM 的两大核心。
